# Crimson Horde: Survivors

⚔️ **Crimson Horde: Survivors** je rogue-lite survival hra inspirovaná tituly jako *Vampire Survivors*. 

## 🎮 Herní prvky
- **Ovládání:** Pohyb pouze pomocí `W`, `A`, `S`, `D` (nebo šipek).
- **Autoshooting:** Hrdina sám zaměřuje a útočí na nejbližší nepřátele.
- **XP & Level-up systém:** Sbírání drahokamů duší z padlých monster. Při každém postupu na nový level má hráč na výběr ze 3 náhodných posílení (buffů).
- **Bohatý výběr perků:** Rychlost pohybu, kadence střelby, dostřel, plošné poškození (splash), průraznost (pierce), vícenásobné střely (multishot), rotující magické čepele (orbitals), řetězové blesky, regenerace a další.
- **10 Unikátních Stages:** 10 různých zón s narůstající obtížností a unikátními bossy (od Pána Ghúlů po Karmínového Vládce).
- **Statistiky přežití:** Zobrazení celkové doby přežití (Survival Time), zabitých monster a rozdaného poškození.
- **Procedurální zvuk:** Integrované Web Audio ozvučení bez nutnosti externích audio souborů.

## 🚀 Jak spustit
Stačí otevřít soubor `index.html` v libovolném moderním webovém prohlížeči (Chrome, Firefox, Edge, Safari). Nevyžaduje žádnou instalaci ani build kroky.

## 🛠️ Technologie
- Čistý JavaScript (ES6+ Canvas API)
- Web Audio API (procedurální syntéza zvuků)
- HTML5 & CSS3
